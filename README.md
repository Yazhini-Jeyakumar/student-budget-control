# Student Budget Control

A web application for students to manage monthly budgets and expenses.

## Features
- User Login & Signup
- Monthly Budget Planning
- Expense Tracking
- Savings Wallet
- Edit/Delete Expenses
- Firebase Authentication
- Real-time Database

## Technologies Used
- HTML
- CSS
- JavaScript
- Firebase
- Netlify
